## ハマりポイント
### iphone側でデベロッパーモードをONにしているはずなのに、flutter runが失敗する
iPhoneの実機ビルドで発生したエラーと対応
1. Developer Mode disabled エラー
  - 事象: flutter run で「Developer Mode disabled」エラーが発生
  - 原因: iPhoneの設定画面ではデベロッパーモードが「オン」でも、再起動後の確認ダイアログを完了していなかった
  - 対応: デベロッパーモードを一度OFF→ONにして再起動、再起動後の確認ダイアログで「有効にする」をタップしパスコード入力
  2. 信頼されていないデベロッパ エラー
  - 事象: アプリインストール後「信頼されて   いないデベロッパ」ダイアログが表示
  - 原因: 無料Apple IDで署名したアプリは初   回に手動で信頼が必要
  - 対応: 設定 → 一般 → VPNとデバイス管理    から該当プロファイルを「信頼」
